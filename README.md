# 소리 (Sori)

A macOS menu bar app that lists every app currently producing audio and gives
each one its own independent volume slider (0–200%) and mute, plus the
ability to redirect an individual app's audio to a different output device.
Built on Core Audio's process tap API
(`AudioHardwareCreateProcessTap`), not `AVAudioEngine`.

No dock icon, no main window — lives entirely in the menu bar.

## Features

- **Per-app volume & mute** — every app currently producing audio gets a row
  with a live-updating icon, name, percentage, mute button, and a 0–200%
  slider (boost above 100% runs through a soft-clip limiter so it doesn't
  distort).
- **Per-app audio redirection** — send an individual app's audio to a
  different connected output device, independent of the system default.
- **System section** — quick access to the system default output/input
  volume (with a device picker for each) and the separate macOS "alert /
  sound effects" volume.
- Settings persist per app across relaunches; rows stick around (dimmed) for
  apps you've interacted with or that were active this session, even after
  they go quiet.

## Requirements

- macOS 14.4+
- Xcode (this project targets a private/system SPI surfaced publicly in
  `CoreAudio/AudioHardware.h`, available starting macOS 14.2)
- Audio recording (TCC) permission, requested on first use — required by the
  process tap API even though Sori only adjusts volume, not audio content.

## Building

The `.xcodeproj` is generated by [xcodegen](https://github.com/yonaskolb/XcodeGen)
from `project.yml` — don't hand-edit the project file. After adding/removing
a source file or changing build settings:

```bash
xcodegen generate
```

Then build:

```bash
xcodebuild -project sori.xcodeproj -scheme sori -configuration Debug \
  -destination 'platform=macOS' -allowProvisioningUpdates build
```

and diagnostic env vars; see `PROGRESS.md` for current status and open items.
